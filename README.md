# ai-project

A small experimental project exploring practical applications of artificial intelligence.

## Overview

This repository contains experimental materials related to:

- Large Language Models (LLMs)
- Prompt Engineering
- AI-assisted information analysis
- Local AI models
- Structured text processing

## Example

Input:

> Analyze the following information and identify the main topics, entities and key events.

Output:

```text
Topics:
- Artificial Intelligence
- Information Analysis

Entities:
- AI systems
- Large Language Models

Event:
- Experimental analysis
